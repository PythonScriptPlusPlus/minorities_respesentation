## Описание проекта
Мы решили спарсить разные данные по уровню занятости в разных странах, а также данные о положении женщин и различных национальных меньшинствах на рынке труда. Попробуем построить для них различные визуализации и проверить гипотезы. :)

### Цели проекта
1. Сбор и анализ данных о занятости.
2. Исследование положения женщин и национальных меньшинств на рынке труда.
3. Создание визуализаций для наглядного представления данных.
4. Проверка гипотез и построение прогнозов.
